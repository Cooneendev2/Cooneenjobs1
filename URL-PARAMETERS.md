# URL parameter system

Every setting is a parameter in the address. One deployment serves every screen: change the address, not the code.

```
https://<your-site>/?mode=hero&theme=dark&lang=fr&qr=1
```

The easiest way to build an address is the **Display builder** at `/admin` (it lists every parameter below, shows a live
preview and gives you the address to copy).

## Rules

- **Names are not case-sensitive.** `?showLocation=0`, `?showlocation=0` and `?SHOWLOCATION=0` are the same.
- **Switches** take `1` / `0` (also `true`/`false`, `yes`/`no`, `on`/`off`). A bare name (`?qr`) means on.
- **Nothing breaks on a typo.** An unknown parameter, or a value that is not allowed (`?mode=disco`), is ignored and the
  default is used. Numbers outside the allowed range are moved to the nearest allowed value. Add `?diag=1` to see exactly
  what was ignored or adjusted (under `ignoredParameters`); the Display builder shows the same warnings.
- **If a name appears twice, the first one wins.**
- **Text is cleaned**: control characters are removed and length is limited. Text is only ever shown as text, never as markup.
- **"By mode"** in the Default column means the default depends on the display mode (see the next table).
- A setting that does not apply to the chosen mode is simply not used (for example `columns` in the widget).

## Defaults that depend on the mode

| Setting | wall | kiosk | carousel | hero | widget | ticker |
|---|---|---|---|---|---|---|
| `header` (heading band) | on | on | on | off | own heading | – |
| `clock` | off | **on** | off | off | – | – |
| `qr` | off | off | off | **on** | – | – |
| `links` (clickable vacancies) | off | off | off | off | **on** | off |
| `showSummary` | off | off | **on** | off | – | – |
| `rotation` (seconds per page / vacancy) | 20 | 20 | 15 | – | – | – |
| `rows` | automatic | automatic | – | – | **5** | – |
| `fontscale` | 1 | **1.1** | 1 | 1 | 1 | 1 |
| `gap` (design pixels; `density=compact` = 16) | 28 | 28 | – | – | – | – |
| On-screen paging buttons | yes | **no** | yes | no | no | no |

A dash means the setting is not used by that mode (the Display builder greys those settings out).

`mode=kiosk` is the wall display with the signage behaviours switched on. **`kiosk=1` works with any mode** (for example
`?mode=carousel&kiosk=1`): no controls, no links, the mouse pointer hidden, the screen kept awake, larger type, and the kiosk column above.
An explicit `links=1` still turns links on, for example for a touch-screen information point.

## How a few parameters work

**`orientation` and `rotate`.** `orientation=auto` (the default) follows the screen shape: wider than tall means landscape.
`orientation=landscape|portrait` forces the arrangement. `rotate=90|180|270` turns the whole display clockwise, for a screen
that is mounted sideways or upside down and whose operating system is not rotated. The layout then works out its own size
after the turn (a landscape screen with `rotate=90` is laid out as portrait). Use `rotate` **or** rotate the screen in
Yodeck / Windows, not both.

**`columns`, `rows`, `cardsize`.** With none of them set, the wall chooses a grid from the screen shape (see
[LAYOUT.md](LAYOUT.md)). `cardsize=small|medium|large` picks more or fewer cards per page. `columns=5` fixes the columns
and the rows follow; `columns` and `rows` together fix the page completely. More vacancies than fit on a page are shown on
several pages.

**`fontscale`.** Multiplies all text. On the wall, cards are fixed in size, so above 1.2 the automatic grid switches to fewer,
larger cards so the bigger text has room. If you choose `columns` yourself the cards stay as you asked and text is shrunk
just enough to fit.

**`featured`.** Talos has no "featured" flag, so featuring is done here: `?featured=CG1234567,CG7654321` (vacancy references
or IDs, any case). Featured vacancies get the gold Featured badge and are shown first. Hero mode picks a featured vacancy
automatically.

**`job` and `hero`** (hero mode). `?job=CG1234567` shows that vacancy (reference or ID). If it is not open, the automatic
choice is used. `hero=auto` (default) = featured if there is one, otherwise the newest; `hero=newest|closing|featured` pick a
different rule.

**`newDays`, `closingDays`.** A vacancy gets **New** for `newDays` days after it was posted, and **Closing soon** when it closes
within `closingDays` days (`closingDays=0` turns it off). Days are London calendar days, and a vacancy is shown until its
closing time passes (Talos closing dates are the end of the day, London time).

**`location`, `department`, `type`.** Filters. `?location=fivemiletown,dungannon` shows vacancies whose location contains any of
those words. This is how one site serves different factories: give each screen its own address.

**`refresh`.** How often the screen asks the server for new data (minutes, with a little random spread so many screens do not
call at once). The server itself only goes back to Talos at about 08:00 and 12:00 London time, so a short interval is cheap.

**`reload`.** Long-running screens reload themselves once a night at this London time (default 03:30, plus up to 15 minutes of
random spread) so memory is released and new versions of the display are picked up. The reload only happens if the site
answers; otherwise it waits and tries again. `reload=off` disables it.

**`motion`.** `auto` follows the device's "reduce motion" setting: with it on, the ticker shows one vacancy at a time instead
of scrolling, and fades are removed. Some signage PCs have animations switched off at system level, which looks the same to
a web page; use `motion=full` there.

## Recipes

| Use | Address |
|---|---|
| Reception screen, one big vacancy with a QR code | `/?mode=hero` |
| Canteen wall, all vacancies, large type | `/?mode=kiosk` |
| Portrait screen, one vacancy at a time, 12 seconds each | `/?mode=carousel&kiosk=1&rotation=12` |
| Wall for the Fivemiletown site only | `/?mode=kiosk&location=fivemiletown` |
| Four columns, compact, with QR codes | `/?mode=kiosk&columns=4&density=compact&qr=1` |
| Screen mounted sideways | `/?mode=kiosk&rotate=90` |
| French interface | `/?mode=kiosk&lang=fr` |
| High-contrast wall | `/?mode=kiosk&theme=highcontrast` |
| Intranet / SharePoint widget, 5 rows | `/?mode=widget&theme=light` |
| Footer strip | `/?mode=ticker` |
| Feature two vacancies | `/?mode=wall&featured=CG1234567,CG7654321` |
| Check what the display understood | add `&diag=1` |
